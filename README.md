# Proxmox Homelab V2

A documented personal homelab focused on virtualization, Linux administration, networking, high availability, automation, and infrastructure engineering.

> **Project status:** Active documentation buildout. Planned experiments are not represented as completed deployments.

## Goals

- Build and maintain a practical environment for systems administration and infrastructure experiments.
- Test reliability, performance, and recovery using repeatable procedures.
- Publish reproducible, sanitized technical documentation.
- Develop evidence-backed projects for a professional IT portfolio.

## Documentation principles

Every project should include an objective, environment and architecture, implementation, troubleshooting, validation, measured results, and lessons learned. Work is marked complete only after it is verified.

**Privacy:** All public materials must be reviewed for personal information, credentials, network identifiers, and sensitive infrastructure details before publication. See [SECURITY.md](SECURITY.md).
